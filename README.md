# Martucci Spectrum

Analizador de espectro en tiempo real (micrófono, archivo o demo).
PWA: Vite + TanStack Start.

## Local

```bash
npm install
npm run dev
```

Abre `http://localhost:8080`.

## Deploy (Vercel)

Conectá este repo al proyecto `martucci-spectrum`.
Build: `npm run build` (preset Nitro `vercel`).
Sin `DATABASE_URL` las migraciones se saltan.

## Branding

No inyecta `extensions.js` ni banners Created with Grok / Remix.
